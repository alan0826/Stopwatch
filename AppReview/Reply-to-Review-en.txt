Hello App Review Team,

Thank you for your patience. We re-examined every build and every piece of metadata we submitted, and we found the inconsistency that most likely made the app appear to hide features.

WHAT HAPPENED

- Build 1 (uploaded August 4) contained only local-notification reminders. It did not contain AlarmKit, a Widget Extension, or any Lock Screen alarm.
- While Build 1 was in review, our App Store Connect metadata (Review Notes, description/promotional text, and screenshots) already described or showed a system alarm feature: “持續響鈴直到停止” (Ring Continuously Until Stopped), which uses iOS 26 AlarmKit and shows a Stop button on the Lock Screen / Dynamic Island. That feature was still in development and was not in Build 1.
- The screen recording we sent on August 14 was captured from Build 1 installed through TestFlight, so it could not show that feature either.
- Build 2 (uploaded September 17) was the first build that contained AlarmKit.

As a result, the metadata described functionality that could not be found in the binary under review. This was our mistake in preparing the submission, not an attempt to hide anything, and we apologize for the confusion it caused.

WHAT BUILD 3 CONTAINS

Build 3, version 1.0 (3), contains exactly the features described in the metadata, and every feature is reachable from the main screen:

1. Interval and one-time reminders: tap + or “新增提醒” (Add Reminder).
2. Local notifications for delivery. Notification permission is requested only when the user taps “開啟背景提醒” (Enable Background Reminders) on the main screen after saving a reminder.
3. On iOS 26 or later: the “持續響鈴直到停止” (Ring Continuously Until Stopped) option for one-time reminders (optionally repeating daily with “每天重複”), which uses AlarmKit. Alarm permission is requested only when the user taps “開啟系統鬧鐘” (Enable System Alarm) on the main screen. The Widget Extension in the bundle only renders this alarm on the Lock Screen / Dynamic Island with a Stop button. On iOS 18–25 the same option is visible but disabled, and labeled as requiring iOS 26.
4. On-device reminder history on the main screen.
5. An About screen (the ⓘ button, top left) listing every feature, the OS requirements, and the exact version/build.

There is no server, remote configuration, downloaded code, WebView, third-party SDK, account, purchase, advertising, or analytics. The app behaves the same for every user. The only difference between devices is the iOS 26 requirement for AlarmKit, which the interface states.
